# VIDORA — مشروع التطبيق الأصلي (Capacitor)
1. أنشئ مستودعاً جديداً على github.com باسم vidora.
2. ارفع كل محتويات هذا المجلد (ومنها المجلد المخفي .github) عبر Add file ثم Upload files.
3. افتح تبويب Actions ثم Build APK ثم Run workflow (أو ينتظر التشغيل التلقائي).
4. بعد نجاحه (نحو 5 دقائق) افتح التشغيل وحمّل VIDORA-apk من Artifacts، وفيه app-debug.apk.
إن لم يُرفع مجلد .github: أنشئ ملفاً من GitHub باسم .github/workflows/android.yml والصق محتوى الملف android.yml.
